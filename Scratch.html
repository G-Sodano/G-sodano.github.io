Scratch Maze Game

This is my second maze project created using Scratch.

Use the arrow keys to move in respected direction

Dave the Beetle is one hungry lad. Stumbling upon an unattended picnic, he thinks he’s found free food… but quickly realizes he’s trapped inside a maze of dangerous walls and obstacles. With the humans returning soon, what seemed like a feast turns into a race to escape. Guide Dave through the maze, avoid hazards, and make it out before it’s too late.

This project demonstrates skills involving game development using Scratch, including movement mechanics, collision detection, randomized obstacle behavior, and event-driven programming. I implemented punishment systems for wall collisions, along with clear win and lose conditions using broadcast logic. The game also features level progression, timing systems, and user feedback elements, showcasing both technical coding ability and game design thinking.
