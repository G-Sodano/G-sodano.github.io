Kaggle Data Analysis

Workout Performance Analysis Using Kaggle

This project analyzes gym member data to better understand how different fitness variables compare to calorie expenditure. Using Python language, I explored patterns within the dataset and created new variables to gain deeper insight into exercise efficiency.

One key step in the analysis was using code to calculate Body Mass Index (BMI) using each individual’s weight and height. This allowed me to examine how body composition may influence calories burned.

I then compared multiple factors to calories burned. I was able to identify which factors appeared to have a stronger relationship with calorie expenditure. For example, session duration showed a clear impact, as longer workouts generally resulted in higher calories burned. On the other hand, BMI showed a weaker relationship, suggesting that it may not be the primary driver of calories burned during a session.
